# 🐱 CATS (Creative Assistant Tools Suite)

ComfyUI 插件包，提供多种实用工具节点，帮助简化工作流和增强创作能力。

## 节点列表

### 1. 🔤 字符串保存节点 (StringSaveNode)
- **功能**：保存字符串到txt文档，支持单次保存或汇总保存为wildcards格式
- **输入**：文本、保存路径、文件名、保存模式
- **输出**：文本（保持数据流）

### 2. 🎲 随机抽取提示词 (RandomWildcardNode)
- **功能**：从wildcards文件中随机抽取提示词，并与固定提示词合并
- **输入**：wildcard文件路径、抽取数量、种子、固定提示词
- **输出**：随机抽取的提示词

### 3. 📋 顺序提取提示词 (SequentialWildcardNode)
- **功能**：从wildcards文件中按顺序提取提示词，支持添加固定前缀
- **输入**：wildcard文件路径、触发值、固定提示词
- **输出**：提示词、当前索引、文件信息

### 4. 🖼️ 图像序列加载器 (ImageSequenceLoader)
- **功能**：按顺序加载文件夹中的图像，支持批量处理
- **输入**：文件夹路径、触发值
- **输出**：图像、文件名

### 5. 🔢 数值分割节点 (数值分割节点)
- **功能**：将空格分隔的数值字符串分割为6个独立输出
- **输入**：数值字符串
- **输出**：数值1-6

### 6. 🔄 反推提示词保存 (ReversePromptSaveNode)
- **功能**：保存图片反推的提示词到txt文档，支持单张和批量保存模式
- **输入**：提示词、保存路径、文件名、保存模式、图片名称
- **输出**：提示词（保持数据流）

### 7. QwenVL (CATS) (aistudynow_QwenVL)
- **功能**：使用Qwen3-VL多模态大模型分析图像/视频并生成文本描述
- **输入**：图像、视频、自定义提示词
- **参数**：模型选择、量化模式、系统提示词、最大token数、是否使用原图分辨率、种子、种子模式、设备
- **输出**：模型生成的文本描述

## 安装方法

1. 将 `ComfyUI-CATS-tools` 文件夹复制到 ComfyUI 的 `custom_nodes` 目录
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 重启 ComfyUI

## 依赖项

- Python 3.10+
- PyTorch 2.0+
- Transformers 4.40+
- Accelerate 0.26+
- BitsAndBytes 0.43+
- Pillow 9.0+
- qwen-vl-utils 0.0.8+

## 使用示例

### 1. 图像分析示例
1. 添加 `QwenVL (CATS)` 节点
2. 连接图像输入到节点的 `image` 端口
3. 配置模型参数（建议使用 Qwen3-VL-2B-Instruct 和 4-bit 量化以节省显存）
4. 执行工作流，节点将生成图像的详细描述

### 2. 提示词管理示例
1. 使用 `随机抽取提示词` 节点从wildcards文件中随机获取提示词
2. 连接到 `字符串保存节点` 保存生成的提示词
3. 可选择添加固定提示词前缀，增强提示词的一致性

## 注意事项

- `QwenVL (CATS)` 节点首次运行时会自动下载模型，可能需要一些时间
- 模型会缓存到内存中，后续使用相同配置时会更快
- 4-bit量化模式可以显著减少显存占用，适合显存较小的设备
- 视频处理功能支持最多8帧的均匀采样
