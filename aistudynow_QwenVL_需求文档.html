  • ComfyUI 节点API

6. 核心功能逻辑

6.1 模型加载逻辑

def load_model(self, model_name, quantization, device):
    """
    要求：
    1. 使用 transformers.AutoModelForVision2Seq 加载Qwen3-VL模型
    2. 根据quantization参数应用不同的加载配置：
       - "none": 使用torch.float16或bfloat16（根据GPU支持）
       - "4-bit": 使用BitsAndBytesConfig(load_in_4bit=True)
       - "8-bit": 使用BitsAndBytesConfig(load_in_8bit=True)
       - "FP16": 强制torch.float16
    3. 使用AutoProcessor处理图像预处理
    4. 实现模型缓存机制：同配置模型只加载一次，存储在全局变量中
    5. 模型路径：自动从HuggingFace下载，或从ComfyUI/models/llm_checkpoints/加载本地模型
    """

6.2 图像预处理逻辑

def preprocess_image(self, image_tensor, use_original_resolution):
    """
    要求：
    1. 输入：ComfyUI IMAGE张量 [Batch, Height, Width, Channel]，值域[0,1]
    2. 转换为PIL Image或numpy数组 [H,W,C]，值域[0,255]
    3. 如果use_original_resolution=False，将长边缩放到1024（保持比例）
    4. 返回：PIL Image列表（支持batch处理）
    """

6.3 推理逻辑

def analyze(self, image=None, video=None, custom_prompt="", 
            model="Qwen3-VL-2B-Instruct", quantization="4-bit (VRAM-friendly)",
            system_prompt="Describe this image in detail.", 
            max_tokens=1024, use_image_resolution=True, 
            seed=0, seed_mode="fixed", device="auto"):
    """
    要求：
    1. 种子处理：
       - "fixed": 使用指定seed
       - "randomize": 随机生成seed
       - "increment": 在上次seed基础上+1

    2. 设置随机种子（torch.manual_seed）

    3. 确定设备优先级：auto > cuda > mps > cpu

    4. 构建对话消息格式（Qwen3-VL专用格式）：
       messages = [
           {"role": "system", "content": system_prompt},
           {"role": "user", "content": [
               {"type": "image", "image": pil_image},
               {"type": "text", "text": custom_prompt if custom_prompt else "Describe this image."}
           ]}
       ]

    5. 使用processor.apply_chat_template()生成输入文本

    6. 模型推理：
       - inputs = processor(..., return_tensors="pt").to(device)
       - outputs = model.generate(**inputs, max_new_tokens=max_tokens, 
                                  do_sample=True, temperature=0.7)
       - response = processor.batch_decode(outputs, skip_special_tokens=True)[0]

    7. 提取assistant回复部分，去除system和user内容

    8. 返回：(response_text,)
    """

10. 特殊要求

  1. 显存优化：4-bit量化模式下，2B模型显存占用应<3GB，4B模型<5GB
  2. 首次加载：模型首次下载时显示进度条，支持断点续传
  3. 错误处理：模型加载失败时返回友好错误信息，不导致ComfyUI崩溃
  4. 批处理：支持batch_size>1的图像输入，顺序处理
  5. 缓存策略：使用LRU缓存最近2个不同配置的模型，避免频繁切换模型时的重复加载
